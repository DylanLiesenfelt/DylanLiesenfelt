## Currently Working On

**Echoes of Anima**

An open-world RPG built from scratch in Rust with no game engine. You play successive reincarnations of a player character while the world grows and changes around you. The world is the protagonist, not the player, and what you do with each life is yours to decide: scholar, merchant, wandering mage, or something else entirely.

The design came before the code. I wrote the full game design document in an iterative review loop with Claude Fable 5.1, and now in Claude Code with Fable 5.1, it plans each milestone against that document while Opus 5 implements it. It's a managed AI development workflow rather than vibe coding, which keeps the architecture deliberate and the codebase maintainable, and let me see how far these models can be pushed.

**StonksAPI**

A backend service for financial market data, built as an R&D tool for developing and testing trading strategies. It supports backtesting, paper trading, custom indexes, and access to raw market data and news. You can use the hosted version on my site or spin up your own instance and modify the codebase to fit your needs.

## Previously Worked On

**ECHO (Enhanced Cognitive Human Operations)**

A research tool built through the Hacking for Defense (H4D) program in collaboration with the United States Army Aeromedical Research Lab (USAARL). The prototype let researchers record and monitor physiological data through a dashboard powered by LabStreamingLayer, then upload that data to a machine learning abstraction tool so researchers without an ML background could build models from it. The goal was a cognitive state detection model for live aviation environments, and ECHO gives that research a faster path to iteration and testing.
