## Previously Worked On

**ECHO (Enhanced Cognitive Human Operations)**

A research tool built through the Hacking for Defense (H4D) program in collaboration with the United States Army Aeromedical Research Lab (USAARL). The prototype let researchers record and monitor physiological data through a dashboard powered by LabStreamingLayer, then upload that data to a machine learning abstraction tool so researchers without an ML background could build models from it. The goal was a cognitive state detection model for live aviation environments, and ECHO gives that research a faster path to iteration and testing.
