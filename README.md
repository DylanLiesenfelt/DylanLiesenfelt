## Previously Worked On:

- **ECHO (Enhanced Cognitive Human Operations):**

A research tool built as part of the Hacking for Defense program (H4D) in collaboration with the United States Army Aeromedical Research Lab (USAARL). The prototype allowed researchers to record and monitor physiological data via a dashboard powered by LabStreamingLayer. That data could then be uploaded to a machine learning abstraction tool, enabling non-cross-trained researchers to develop ML models from it. The end goal was the development of a cognitive state monitoring/detection model for use in live aviation environments. Our tool provides a stepping stone to enable faster iteration and testing for further research and development on such models.
